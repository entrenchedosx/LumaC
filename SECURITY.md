# Security Policy

LumaC is an early-stage graphics library. If you find a security issue
(e.g. memory-safety bug reachable from public API input), please report
it responsibly:

1. Do not open a public issue with exploit details.
2. Use GitHub's **Security Advisories** ("Report a vulnerability" on the
   repository Security tab) so the details stay private until fixed.
3. Include the affected version/commit, platform, and steps to reproduce.

We aim to acknowledge reports promptly and fix verified issues before
disclosing them. No bug bounty program exists at this stage.
